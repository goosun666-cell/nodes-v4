🛠 一、 部署前的准备工作 (Prerequisites)

为了保证 AI 节点 24 小时稳定运行且不断电不断网，我们强烈建议使用 VPS（云服务器）进行部署，而不是你的个人电脑。

  • 一台海外云服务器 (VPS)： 推荐使用 Ubuntu 22.04 或以上系统。配置要求极低，1核 2G 内存的入门级服务器（如 DigitalOcean, Vultr 或阿里云国际版）即可流畅运行。
  • 基础远程连接工具： Windows 用户可下载 Xshell 或 Termius，Mac 用户直接使用系统自带的终端 (Terminal) 通过 SSH 连接服务器。
  • 一个专属的 Web3 钱包： 准备一个干净的 EVM 钱包（如 MetaMask 新账户），存入少量的 ETH 或 Base 链上的 ETH 作为 AI 代理执行交易的 Gas 费。（⚠️ 警告：绝对不要使用存放你核心资产的主钱包作为节点执行钱包！）
  • 大模型 API Key： 准备一个 OpenAI (GPT-4) 或 Claude 的 API 密钥，这将是你的 AI 代理的“大脑”。

💻 二、 核心实战：OpenClaw 节点部署与配置

通过 SSH 成功连接到你的云服务器后，请按顺序执行以下命令。

Step 1: 基础环境配置

我们需要确保服务器安装了最新的 Python 环境和代码拉取工具 Git。在终端中逐行运行并回车：

Bash 
# 更新系统依赖包
sudo apt update && sudo apt upgrade -y

# 安装 Python 和 Git
sudo apt install python3 python3-pip python3-venv git -y

Step 2: 克隆源码并安装依赖

将 OpenClaw 的核心代码拉取到你的服务器，并创建一个独立的虚拟环境以防止代码冲突：

Bash 
# 克隆官方仓库
git clone https://github.com/OpenClaw/OpenClaw.git
cd OpenClaw

# 创建并激活 Python 虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装项目所需的核心依赖包
pip install -r requirements.txt

Step 3: 配置 .env 核心参数 (最关键的一步)

OpenClaw 的灵魂在于它的配置文件。我们需要填入你的 API 密钥和 Web3 钱包信息：

Bash 
# 复制环境变量模板
cp .env.example .env

# 使用 nano 编辑器打开 .env 文件进行修改
nano .env

在打开的编辑器中，使用键盘方向键移动光标，找到并修改以下核心参数：

Ini / TOML 
# 1. 填入你的大模型 API Key (这里以 OpenAI 为例)
LLM_API_KEY="sk-your-api-key-here"
LLM_MODEL="gpt-4-turbo" 

# 2. Web3 钱包配置 (填入你准备好的专用节点钱包私钥)
PRIVATE_KEY="你的专属节点钱包私钥"

# 3. RPC 节点配置 (建议使用 Base 链以降低交互成本)
RPC_URL="https://mainnet.base.org"

(修改完成后，按 Ctrl+O 保存，按 Enter 确认，然后按 Ctrl+X 退出编辑器。)

Step 4: 启动你的第一个自主经济代理人 (AEA)

一切准备就绪！为了让节点在你关闭电脑后依然在服务器后台运行，我们使用 tmux 工具启动它：

Bash 
# 开启名为 openclaw_node 的后台保护进程
tmux new -s openclaw_node

# 启动 OpenClaw 主程序
python main.py

当你看到终端开始输出 AI 的思考日志（Thinking...），并成功连接到区块链网络时，恭喜你，你的第一个 OpenClaw AI 节点已经成功觉醒！

(提示：如果要退出当前终端但保持节点运行，请按 Ctrl+B，松开后再按 D。)
